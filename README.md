# DraveWeerAndroid

Het weer op je Android-telefoon, groot en duidelijk: nu, per uur, per week, regen per kwartier, buienradar en een stem die het weer voorleest.

## ⬇️ Downloaden (Android-telefoon)

### [👉 Download DraveWeerAndroid 0.3.1](https://github.com/mbrv4ever/DraveWeerAndroid/releases/latest)

1. Open de link **op je telefoon** en download het **.apk**-bestand.
2. Tik op het bestand. Vraagt Android of je "onbekende apps" wilt toestaan? Tik op **Instellingen** en zet het aan.
3. Tik op **Installeren**. De eerste keer vraagt de app of hij een icoon op je startscherm mag zetten.

In de release staat ook de **snelgids** (PDF) met uitleg.

## Vanaf de broncode

Geschreven in Python met pygame. Op de pc start je `main.py` om te testen. De apk bouw je met **buildozer** (zie `buildozer.spec`).
